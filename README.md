# SciRust-Verify

Verification, evidence, provenance and trust layer for the SciRust ecosystem.

SciRust-Verify turns *claims* ("this build is deterministic", "these tests pass",
"this kernel matches its oracle") into structured **Evidence Dossiers**: versioned,
integrity-checked bundles that record exactly what was executed, under which
scope, which properties were checked, what raw evidence was captured and which
verdicts that evidence actually justifies.

> Claims are cheap. Evidence is expensive. SciRust-Verify preserves the difference.

**Status: V0.1 foundation under active development.**
